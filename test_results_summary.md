## 1. Executive Summary

This report evaluates the **Stage 3 Machine Learning Sequence Classifier** within the Kid-Friendly Content Moderation pipeline. Operating strictly offline on local compute, the model receives scene-by-scene narrative descriptions generated by visual perception engines and assigns calibrated probabilistic determinations: **`SAFE` (Kid-Friendly)** or **`UNSAFE` (Not Kid-Friendly)**.

By leveraging **DeBERTa-v3** (Disentangled Bidirectional Attention), the classifier resolves the critical flaws of legacy bag-of-words and TF-IDF models:
* **Contextual Comprehension**: Understands full grammatical syntax, sentence semantics, actions, and negations (e.g., differentiating *"no weapons present"* from *"weapons present"*).
* **Elimination of Keyword Bias**: Self-attention binds actions (verbs) directly to objects and scenes, completely eliminating spurious demographic correlations.
* **Calibrated Decision Boundary**: Employs asymmetric risk calibration ($P(\text{UNSAFE}) \ge 0.35$) to prioritize child safety and minimize false negatives on hazardous content.

## 2. Model Architecture & Training Hyperparameters

| Component | Specification |
| :--- | :--- |
| **Model Backbone** | `microsoft/deberta-v3-base` (184M Parameters) |
| **Pretrained Mechanism** | Disentangled Attention (separate content and relative position vectors) |
| **Sequence Head** | `LayerNorm` $\rightarrow$ `Dropout(p=0.1)` $\rightarrow$ `Linear(768, 2)` |
| **Tokenization** | Subword Fast BPE Tokenizer (`max_length = 512`) |
| **Optimization** | AdamW (`learning_rate = 2e-5`, `weight_decay = 0.01`) |
| **Loss Function** | `CrossEntropyLoss` with Balanced Class Weights |
| **Precision** | Standard IEEE 754 Float32 (CPU & GPU execution) |

## 5. Architectural Comparison: Legacy TF-IDF vs. Modern DeBERTa-v3

| Evaluation Criterion | Legacy Classical Model | Modern Transformer Architecture |
| :--- | :--- | :--- |
| **Backbone** | TF-IDF (Bag-of-Words N-grams) | `microsoft/deberta-v3-base` |
| **Contextual Awareness** | Zero (isolated word frequencies) | Deep bidirectional self-attention across 12 layers |
| **Negation Handling** | Fails (*"no violence"* treated same as *"violence"*) | Accurate grammatical parsing of negative clauses |
| **Demographic Fairness** | Susceptible to keyword correlation | Action-verb contextual binding; unbiased |
| **Feature Dimension** | 25,000 sparse count bins | 768-dimensional dense contextual embeddings |
| **Inference Mode** | Scikit-Learn linear regression | PyTorch deep neural sequence classification |
